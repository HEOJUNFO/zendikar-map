# 게임 전면 개편 — 1막부터

2026-10-16 사용자 요청. 이전 게임은 미구현 saga 3 / ZNR을 현재 지도와 같은 시점으로 잘못 취급했고, 수정 과정에서도 지도 최신인 2막 BFZ를 시작 막으로 잘못 골랐다. **우리는 1막부터 개발한다.** 이번 개편은 시대·장소·적·공간·무기·보상 도상의 교체다. 개편 완료 문서가 아니며 실제 게임 검증이 남아 있다.

## 기준과 완료 조건

- `src/data/sagas.ts`: 실제 지도는 saga 1(ZEN/WWK/ROE)과 saga 2(BFZ/OGW). 미구현 ZNR은 게임의 현재가 아니다.
- `game/gameplay/content/campaign.json`: 게임 1막은 지도 saga 1의 ZEN→WWK→ROE(2009–10) 전체 순서다. 시작 구간은 ZEN의 타짐 에메리아 하층·주변 폐허 원정이다. 최신 지도 사가를 게임 시작 막으로 선택하지 않는다.
- 플레이어는 이름 없는 원정대원이다. 시작은 위험한 자연·탁류·유적 탐험이고, WWK의 격동과 ROE 해방 이후의 생존·탈출로 이어진다. 아이오나가 막은 상층을 정복하거나 정사 영웅의 행동·타이탄 해방/격파를 대신하지 않는다.
- 기존 리듬 FPS 조작, 반박자 대시, 더블점프를 유지한다. 승인된 증강은 이롭게 작용하며 신규 체력·골드 비용과 강제 이동 패널티를 붙이지 않는다.

## 아트 검토와 현재 차단

현재 출처는 `src/data/phase1.ts`의 다섯 ZEN 카드별 공식 근거 및 `src/data/locations.ts` 에메리아의 ZEN 역사다. 생물의 시기뿐 아니라 실제 대륙과 장소도 검사한다. 예를 들어 아이오르 폐허는 아쿰이므로 타짐 시작 무대로 사용할 수 없다. 건축 내부 배치·전투 역할·공격 패턴은 프로젝트 창작이다.

- 기존 v1/v2 카드 그림과 타짐 동물 모델은 1막 사용 검토를 보류한다. 원본과 해시는 보존한다.
- `game/art-work/saga2/`의 BFZ 엘드라지·바다 관문 콘셉트는 잘못 고른 시작 막의 자료이므로 현재 사용하지 않는다. 3D 게임 렌더가 아니다.
- 승인한 생성 5회는 올바른 ZEN 대상에 제출해 완료했다. 무료 지원 검사 후 별도로 승인한 보아 리깅·보아 이동·드레이크 리깅 3회도 완료했다. BFZ 제출은 0회이며 추가 작업을 자동 재제출하지 않았다.
- 사용자 지시는 **Studio 웹 JWT 직접 HTTP API**다. MCP 복구를 선행 조건으로 삼지 않는다. 토큰은 로컬 마스킹 입력과 프로세스 메모리로만 처리하며 채팅·파일·인수·로그에 기록하지 않는다.
- 직접 만든 절차적 대체 모델은 실제 렌더 후 형태·재질 기준 미달로 제외했다. 실패 결과와 생성 원본은 `build/saga2-overhaul/rejected-bfz-models/` 및 같은 폴더의 진단 렌더에 보존한다. 생산 팩에 연결하지 않았다.
- 게임 C++/팩의 교체와 실제 플레이 검증이 끝나기 전에는 ‘1막 완성’으로 보고하지 않는다. ZEN→WWK→ROE 세 구간 진행과 보상 유지, ZEN 몹 5종의 실제 스킨·29개 DCC 클립이 현재 게임과 품질 뷰어에 연결되어 있다. 진행·한글 HUD·팩 소비·개체별 팔레트·소스/GPU 변형은 실제 검증한다. 전장·장비·카드의 전체 개편과 AAA 동작 품질 승인은 아직 완료되지 않았다.

## 실행 기록

- 시작: 2026-10-16. 기존 미커밋 상점·모델 변경은 보존했다.
- 지도 연결·웹 JWT 직접 실행 계획 검사 8개 통과. 실제 세 구간 전투·포털 진행과 보상 유지 `sim_probe` 통과. 새 HUD의 한글·여백·다음 구간/1막 완료 표시 `presentation_probe` 통과. 후자는 기존 4종 모델 팩을 사용하는 UI 검증이며 신규 5종 렌더 증거가 아니다.
- UI 재작업: 안내 문구 추가로 메뉴 높이가 넘쳐 한 줄로 줄였고, 완료 제목도 기존 폭 안에 드는 ‘1막 완료’로 조정했다. UI 수리 빌드 후 프로브 통과. 동일한 시뮬레이션 검사를 이유 없이 반복하지 않았다.
- 반복 빌드와 불필요한 전체 검사는 하지 않는다. 최종 통합은 모델·공간·장비·UI 입력이 안정된 뒤 한 번 한다.
- 속도 비교용 동등 범위의 이전 실측이 없어 5배 향상을 주장하지 않는다. 두 차례의 시작 시대 오판, 바인딩 표면의 UV seam, 보아 이동 프리셋의 접지 실패로 재작업이 발생했다. 유료 작업은 5+3회로 종료했다. 실제 리그 구현·현재 검증·남은 한계는 `docs/game-animation-quality.md` 및 `game/art-work/act1/STATUS.md`를 따른다.
