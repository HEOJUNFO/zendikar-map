- 사용자 결정 2026-11-07: 같은 데이터를 픽셀 아트로 그린 지도를 따로 된 페이지 `/pixel`(`pixel.html` → `src/pixel/`)로 단계마다(S1–S9) 만든다 — 결정 D1–D7·단계·피할 것은 `docs/pixel-plan.md`. 지금은 S26(시점별 지도만 — 사가·페이즈 보기는 하지 않는다, 사용자 결정 2026-11-07) — 해안·내해·숲을 확대 단계(한 픽셀 = 16 … 0.25 단위)마다 256² 타일로 Worker 가 그리고(기본 16비트 팔레트·2×·디더링, 시험 스위치 `?pal`·`?s`·`?shore`), 그 위 DOM 층에 장소·대지 카드 기호와 이름·지역 이름·대륙명, 오른쪽(휴대폰은 아래) 픽셀 패널을 둔다(페이즈를 끈 지도의 것만, 고른 것은 지금 지도와 같은 `#` 주소). 글꼴은 Galmuri11(OFL)을 줄여 이름을 바꾼 'Zendikar Pixel'(`src/pixel/fonts/`, 다시 만들기 `scripts/pixel/font.sh`), 첫 조각의 이름·자리는 `vite/pixelMarks.ts` 의 `virtual:pixel-marks`, 이름 배치는 `labels.ts` 를 복사한 `src/pixel/labels/layout.ts`. 바탕 지형(S4)은 `scripts/pixel/terrain.mjs` 가 지금 지도의 지형 셈을 Node 에서 그대로 돌려 뽑은 `virtual:pixel-terrain`(`vite/pixelTerrain.ts`)을 Worker 가 타일에 그리고(`src/pixel/raster/terrain.ts`, 그림판 `terrainSprites.ts`), 흩뿌린 기호만 이름 상자(`src/pixel/labels/holes.ts`)를 비킨다. 움직이는 효과(S5 — 폭포·용암·소용돌이·간헐천)는 pixelfx core 를 옮긴 `src/pixel/vendor/pixelfx/` 와 지도 크기로 고친 `src/pixel/fx/effects/*.js` 를 `src/pixel/fx/layer.ts` 가 구워 타일 위 캔버스에 12fps 로 그린다(자리는 타일 Worker 가 낸 `FxSpot` — 데이터 id 와 바탕). 시점별 바탕(S6 — `?time=1..6`)은 `scripts/pixel/periods.mjs` 가 지금 지도의 `createPeriods().at(단계, ctx)` 를 Node 에서 그대로 돌려 바탕과 다른 몫만 뽑고(`virtual:pixel-period-<단계>`·`virtual:pixel-times`·`virtual:pixel-period-notes`), Worker 가 바뀐 자리 상자에 닿는 타일만 그 시점으로 그린다(`src/pixel/raster/period.ts`, 열쇠 `t|<이름 상자 지문>|p<단계>` — 닿지 않는 타일은 끈 지도와 같은 바이트, `pixel-regress --time t` 가 본다). 주 스레드 몫은 `src/pixel/time.ts`. 페이즈 그림(S7 — 시점마다의 세계 지도 그림, 지역 상세의 대상은 패널에만)은 `scripts/pixel/figures.mjs` 가 빌드할 때 단계마다 몫 번호 그림으로 굽고(`vite/pixelFigures.ts` 의 `virtual:pixel-figures`·`virtual:pixel-fig-<조각>`), `src/pixel/figures/store.ts` 가 보이는 조각만 받아 팔레트로 칠해 `.pixel-figs` 캔버스에 그린다 — 시험 `node scripts/qa/pixel-figures.mjs`(`pnpm dev` 뒤 — 지금 지도의 `?map` 과 시점마다 같은지). 지역 상세(S9)는 가장 깊은 단계(한 픽셀 0.25 단위)에서 24곳 모두 — `scripts/pixel/childmaps.mjs` 가 지금 지도의 그림(`src/map/childmaps/<id>.ts`)을 보기(끔·시점 1–6)마다 몫 번호 그림으로 굽고(가장자리 띠는 겹 마스크를 바이어 문턱으로), 지역 상세에 닿는 깊은 확대 칸의 기호를 보기마다 지금 지도의 `fineOverlay` 로 다시 뿌려 보기 비트를 단다(`fine.cv`). Worker 가 그 타일(열쇠 `|c<보기>`)에 그림을 얹고 그 범위의 세계 지도 강·단애·한 점 기호·헤드론을 물린다(`src/pixel/raster/child.ts`). 이름·숨길 지역 이름·표시 이름 쪽은 `src/pixel/detail.ts`, 그곳의 대상은 그림(S7)처럼 가장 깊은 단계에서만(`figures.mjs` 의 `DETAIL_LEVEL`), 장소 패널의 '가까이 보기'. 스크린샷 `node scripts/qa/pixel-shot.mjs <폴더> 이름='?view=…' …`(`pnpm dev` 뒤). 범례(S10)는 지금 지도의 범례 줄·글을 픽셀 그림으로(`src/pixel/legend/`), 시험 `node scripts/qa/pixel-legend.mjs`(`pnpm dev` 뒤). 키보드·초점 시험 `node scripts/qa/pixel-a11y.mjs`(`pnpm dev` 뒤). 시험은 `node scripts/qa/pixel-regress.mjs`(타일 이음매·차례, `--save`·`--compare` 타일 해시 — Node 만), `node scripts/qa/pixel-fx.mjs [--browser]`(효과의 고리 이음매·데이터 id·보일 때만 도는 시계 — `--browser` 는 빌드 미리보기 뒤), `node scripts/qa/pixel-terrain.mjs`(그린 지형마다 데이터가 있고 데이터마다 그려지는지, `--sheet <png>` 그림판 — Node 만), `node scripts/qa/pixel-fine-cells.mjs`(깊은 확대의 기호는 200 단위 칸마다 따로 된 조각 `virtual:pixel-terrain-fine-<cx>_<cy>` 이고 Worker 는 타일에 닿는 칸만 받는다 — 그렇게 그린 타일이 전부를 붙여 그린 타일과 바이트까지 같은지, `--selfcheck` 는 칸 하나를 빼 시험이 잡는지 — Node 만), `node scripts/qa/pixel-labels.mjs`(모든 이름이 en·ko 로 어느 단계에선가 보이는지·겹침 — Node 만), `node scripts/qa/pixel-marks.mjs`(기호 누르기·끌기·Tab·패널 — `pnpm dev` 뒤)와 `node scripts/qa/pixel-perf.mjs`(끌기 프레임 간격 — `pnpm dev` 뒤).
- 따로 빌드한다(`vite/pixel.config.ts`, `pnpm build` 가 두 번 빌드, Vercel 은 `vercel.json` 의 `buildCommand`·rewrites) — 지금 지도의 사가 보기는 바이트까지 그대로여야 하고(`saga-regress`·`labels-diff`), 지금 지도의 모듈은 고치지 않고 순수한 데이터·기하만 가져다 쓰거나 복사한다. 예외는 S8 의 '픽셀 지도로 보기' 링크(`src/App.tsx` 의 `pixelMapHref` — 펼친 머리말의 마지막 줄, 누르는 때 지금 주소로) 하나다 — 왕복 시험은 `node scripts/qa/pixel-link.mjs`(`pnpm dev` 뒤).
- 위의 설정 원칙과 저장한 선호(추정 자리에 다른 표시 모양 없음, 카드 모아보기 없음)는 픽셀 지도에도 그대로다.
- pixelfx(MIT, `a841596`)는 S5 에서 쓰는 core 만 `src/pixel/vendor/pixelfx/` 에 복사했다(고친 것은 그 README). 효과는 지도 크기로 고쳐 `src/pixel/fx/effects/` 에 두고, `references/pixelfx` 의 작업대(`src/fx/zendikar/`)에서 render·check 로 다듬는다. `tools/` 는 `references/pixelfx`(`pnpm refs`)에서 돌리고, 프로젝트에 설치한 pixelfx 스킬도 그 checkout 을 쓴다. Patch Pixel 글꼴은 쓰지 않는다.
- 픽셀 지도의 글자는 'Zendikar Pixel'(Galmuri11 을 줄인 것) 12·24px 로만 쓴다. 'Galmuri' 는 OFL 예약 글꼴 이름이라 고친 글꼴 파일에 그 이름을 쓰지 않는다 — 글자를 더 넣으려면 `scripts/pixel/subset_font.py` 의 범위를 고쳐 `scripts/pixel/font.sh` 로 다시 만든다.
