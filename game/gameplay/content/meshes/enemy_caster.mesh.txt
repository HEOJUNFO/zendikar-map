# 원거리형 적 — 깨어난 헤드론 조각. 떠 있는 헤드론(삼각형 면 여덟 개의 길쭉한 팔면체 — docs/lore.md)의 룬이 살아나 빛을 모아 쏜다.
# 헤드론이 스스로 움직여 공격한다는 공식 자료는 없다 — 이 게임이 지었다. 유적에 뜬 여느 헤드론(회백색, 룬이 잠들었다)과 달리 짙은 돌에 주황 룬이 빛난다.
# 통짜로 움직이고, 모으기는 그리는 쪽이 색·크기로 보인다.
# 앞은 -z, 발밑(떠 있는 자리의 바닥) 가운데가 원점. 부딪히는 몸은 시뮬레이션이 정한다 (가로 1.1 m, 높이 2.4 m).

color shell    #2f3c66
color shell_lt #46578c
color shard    #39435c
color ember    #ff8a3a glow

oct shell    0 1.5 0   0.5 0.95 0.5
oct shell_lt 0 1.5 0   0.36 1.03 0.36 rot 45 0 0
# ── 살아난 룬 — 허리를 두른 띠와 앞면의 눈

box ember    0 1.66 -0.4   0.2 0.16 0.1
