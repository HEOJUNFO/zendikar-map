# 막음돌 — 틀의 문 자리 가운데 이 방에서 문이 나지 않은 곳(이웃 방이 없는 쪽)의 문틀 속을 메운 돌. 막돌을 쌓아 메우고 가운데에 죽은 룬의 돌판을 박았다
# (빛나지 않는다 — 룬은 활성화될 때만 빛난다, docs/lore.md).
# 하늘거주지의 문이 이렇게 막혀 있다는 공식 자료는 없다 — 이 게임이 지었다.
# 방 가운데가 원점, 북쪽(-z) 문 자리(x -2 … 2, 벽감은 z -16 … -17)에 놓은 모양으로 적는다 (다른 쪽은 90 도씩 돌려 쓴다). 굽지 않는다 — 문 자리 안쪽의 프로브로 비춘다.
# 부딪히는 것은 block 하나다 (도형은 부딪히지 않는다).
