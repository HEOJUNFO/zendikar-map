Browser QA checks safe-panel bounds, single-line titles, actual selected frame filenames, opaque text panels and at least 4.5:1 text/frame contrast, as well as overflow. The current twelve-card preview measured a minimum contrast of approximately 5.8:1.

Run `node game/tools/art/prepare-card-art.mjs` from the repository root. It validates PNG dimensions and alpha contracts, then uses the existing game image compiler to produce RGBA QOI images under `prepared/`: frames at 512 × 768 and illustrations within 640 × 360. `prepared/asset-index.json` records source and output dimensions, bytes and SHA-256 hashes. Original PNGs remain unchanged.

The same command creates `build/shop-card-art/preview.html`, using the project's Pretendard font and separate image/text layers. With the existing Vite server, run `node game/tests/card-art.browser.mjs --base http://127.0.0.1:5181` to verify actual image decoding, Korean font readiness and text-region bounds, and capture all cards plus each of the three visual tiers. Preview text is HTML, not part of the delivered artwork. Capture evidence and PNGs stay under the ignored `build/shop-card-art/` directory.
