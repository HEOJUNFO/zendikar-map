# 옴라 모델링용 멀티뷰 v2

`normal/`과 `corrupted/`는 각각 독립적인 3D 모델링 입력 세트다. 각 PNG는 1162×1353 RGBA이며 배경이 투명하다. 모두 같은 굽은 노파를 T포즈로 묘사한다. 흑화형은 머리카락 전체가 검붉은색이다.

| 입력 칸 | 파일 | 카메라 |
| --- | --- | --- |
| 정면 | `front.png` | 인물 정면 |
| 왼쪽 | `left.png` | 인물의 왼쪽에서 촬영, 얼굴이 이미지 오른쪽을 향함 |
| 오른쪽 | `right.png` | 인물의 오른쪽에서 촬영, 얼굴이 이미지 왼쪽을 향함 |
| 뒷면 | `back.png` | 인물 뒷면 |

정면/측면/후면은 별도로 생성한 그림이므로 소매 찢김, 허리 장식, 손가락과 옷 주름의 위치가 완전히 일치하는 CAD 도면은 아니다. 모델 생성 뒤 그 부분과 굽은 척추의 실루엣을 직접 확인한다. 흑화형은 가능하면 평상형의 같은 메시·리깅을 재사용하고 머리색·피부 균열·눈 재질로 분기한다.
