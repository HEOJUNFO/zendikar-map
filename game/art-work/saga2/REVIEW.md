# 보류: 2막 콘셉트

사용자는 1막부터 개발하도록 바로잡았다. 아래 BFZ 콘셉트는 현재 시작 막의 승인 자료가 아니며 유료 모델 생성에 제출하지 않았다. 승인한 5회 한도를 이 잘못된 시작 막에 사용하지 않는다.

# BFZ 교체 아트 검토

2026-10-16. 생성은 내장 imagegen을 사용했다. 정확한 프롬프트는 `prompts-v1.json`, 검토 이미지 해시는 `review.json`에 남긴다. 이 폴더는 생산 에셋 팩에 연결되지 않았다.

| 결과 | 픽셀 검토 | 사용 범위 |

별도의 절차적 3D 대체 후보 5종은 진단 렌더에서 뼈의 네모난 구멍·단순한 덩어리·원본과 다른 팔다리 비례가 확인되어 품질 미달로 제외했다. 후보 파일, 해시와 렌더는 무시되는 `build/saga2-overhaul/`에 보존한다. 이미지 콘셉트나 Blender 진단을 게임의 실제 WebGPU 렌더 증거로 쓰지 않는다.
